# 22. 3 Sum

← [Two Sum](21-two-sum.md) · [Part 14 index](README.md) · Next → [4 Sum](23-4-sum.md)

> [!abstract] Problem at a glance
> **Task:** Return all unique triplets `[a, b, c]` with `a + b + c = 0`, each sorted, in lexicographic order.
> **Key insight:** Sort. Fix `nums[i]`, then two-pointer `l, r` over the rest for sum `−nums[i]`. Skip equal values for `i`, and after each hit, skip equal values for `l` and `r`. That avoids duplicates without a set, in O(n²).

## 1. Problem

Given an integer array `nums`, return all distinct triplets `[nums[i], nums[j], nums[k]]` with distinct indices such that the sum is `0`. Each triplet is in non-decreasing order, and the list is sorted.

| Input | Output | Why |
|---|---|---|
| `nums = [-1, 0, 1, 2, -1, -4]` | `[[-1, -1, 2], [-1, 0, 1]]` |  |
| `nums = [0, 0, 0, 0]` | `[[0, 0, 0]]` | one triplet, not four |

**Constraints:** `3 ≤ n ≤ 3000`, `−10⁵ ≤ nums[i] ≤ 10⁵`.

---

## 2. Approaches at a glance

| Approach | Idea | Time | Space |
|---|---|---|---|
| All triples + set | three loops, sorted tuple into a set | O(n³ log m) | O(#triplets) |
| Fix one + hash set for the third | for each pair (i, j), look up −(a + b) among indices between | O(n² log m) | O(n + #triplets) |
| Sort + two pointers | fix i; l = i + 1, r = n − 1; skip duplicates | O(n²) | O(1) beyond the output (sorting aside) |

---

## 3. All triples + set

**Intuition.** Try every triple, sort it, and dedupe with a set.

```python
def three_sum_brute(nums):
    n, res = len(nums), set()
    for i in range(n):
        for j in range(i + 1, n):
            for k in range(j + 1, n):
                if nums[i] + nums[j] + nums[k] == 0:
                    res.add(tuple(sorted((nums[i], nums[j], nums[k]))))
    return sorted(list(t) for t in res)
```

**Complexity:** time **O(n³ log m)**, space **O(#triplets)**.

---

## 4. Fix one + hash set for the third

**Intuition.** For each `i`, scan `j > i` with a set of values seen between `i` and `j`; the third value is `−(nums[i] + nums[j])`. Still needs a global set to dedupe.

```python
def three_sum_hash(nums):
    n, res = len(nums), set()
    for i in range(n):
        seen = set()
        for j in range(i + 1, n):
            third = -(nums[i] + nums[j])
            if third in seen:
                res.add(tuple(sorted((nums[i], nums[j], third))))
            seen.add(nums[j])
    return sorted(list(t) for t in res)
```

**Complexity:** time **O(n² log m)**, space **O(n + #triplets)**.

## 5. Sort + two pointers

**Intuition.** With the array sorted, for a fixed `i`, the pair sum `nums[l] + nums[r]` moves monotonically: `l++` raises it, `r−−` lowers it. Duplicate triplets only arise from equal values in the same role, so skipping repeats for `i` (compare with `i − 1`) and for `l`/`r` after a hit removes them all. The output comes out in lexicographic order for free.

**Algorithm**

1. Sort.
2. For `i` in `0..n − 3`: skip if `i > 0 and nums[i] == nums[i − 1]`. Optional: break if `nums[i] > 0`.
3. `l = i + 1`, `r = n − 1`. While `l < r`: `s = nums[i] + nums[l] + nums[r]`.
4. `s < 0` → `l++`; `s > 0` → `r−−`; `s == 0` → record, `l++`, `r−−`, then skip duplicates of `nums[l − 1]` and `nums[r + 1]`.

**Dry run** — sorted `[-4 -1 -1 0 1 2]`: i=0 (−4): no pair sums to 4. i=1 (−1): l=2, r=5 → −1−1+2 = 0 ✓ record; l=3, r=4 → −1+0+1 = 0 ✓. i=2: duplicate of −1, skip. i=3 (0): l=4, r=5 → 3 > 0. Done.

**C++**
```cpp
vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> res;
    int n = nums.size();
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        int l = i + 1, r = n - 1;
        while (l < r) {
            int s = nums[i] + nums[l] + nums[r];
            if (s < 0) l++;
            else if (s > 0) r--;
            else {
                res.push_back({nums[i], nums[l], nums[r]});
                l++; r--;
                while (l < r && nums[l] == nums[l - 1]) l++;
                while (l < r && nums[r] == nums[r + 1]) r--;
            }
        }
    }
    return res;
}
```

**Python**
```python
def three_sum(nums):
    nums.sort()
    n, res = len(nums), []
    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                res.append([nums[i], nums[l], nums[r]])
                l += 1; r -= 1
                while l < r and nums[l] == nums[l - 1]:
                    l += 1
                while l < r and nums[r] == nums[r + 1]:
                    r -= 1
    return res
```

**Complexity:** time **O(n²)**, space **O(1) beyond the output (sorting aside)**.

## Edge cases

- All zeros.
- No triplet.
- Many duplicates of one value.

---

## Common mistakes

1. Skipping `i` duplicates with `nums[i] == nums[i + 1]`, which drops valid triplets like `[-1, -1, 2]`.
2. Forgetting to move both pointers after a hit → infinite loop.
3. Dedupe with a set of lists: works, but is slower and unhashable in Python without tuples.
