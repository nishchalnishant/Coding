# Striver A2Z DSA Course: Structured Notes

← [Repo home](../README.md)

> [!abstract] What this folder is
> **Covers:** Enriched notes for every category of the [Striver A2Z DSA course](https://takeuforward.org/learning/dsa/breaking-the-myth?source=strivers-a2z-dsa-sheet&category=fundamentals-of-programming). There is one folder per course category and one note per lesson, in course order.
> **Each note has:** the source lesson link, core ideas in original wording, extra examples, pseudocode with C++/Java/Python where useful, mermaid diagrams, common mistakes, practice exercises and `#flashcard` cards.
> **How it relates to the rest of the repo:** this is the *course track*, a linear path from zero. The rest of the repo is the *interview track*, which is topic-first and tier-tagged. Notes cross-link where the two meet.

## How to use these notes

1. **Read the lesson on takeuforward first, then the note.** The note restructures the lesson and adds to it. It is not a replacement for solving the problems yourself.
2. **Do every practice exercise on paper** before you write any code. Part 1 is entirely about this habit.
3. **Review the flashcards** with spaced repetition. The export command is in the [repo README](../README.md#flashcards-147-cards-spaced-repetition).
4. When a topic overlaps the interview track, follow the **Interview track →** link at the bottom of the note for tier-tagged problems.
