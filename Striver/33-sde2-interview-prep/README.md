# Part 33: SDE 2 Interview Preparation

← [Striver course map](../README.md) · [Study plan](../STUDY_PLAN.md)

> [!abstract] What this part adds
> The 32 preceding parts provide broad DSA coverage. This part fills the gap between solving algorithm problems and demonstrating mid-level software engineering judgment. It covers system design, object-oriented/low-level design, core CS, coding interview execution, testing, and behavioral/project evidence.
>
> Interview formats vary by company, team, geography, and role. Treat this as a broad preparation baseline and confirm the actual loop with the recruiter. For example, Amazon's official SDE II guide describes coding, system design, and behavioral assessment; Meta's published full-loop guide describes coding, design, and behavioral interviews.

## Priority

1. Keep DSA sharp: mixed medium problems, occasional hard problems, and timed mocks.
2. Prepare one system design and one object-oriented design interview format.
3. Refresh core CS concepts that connect directly to the candidate's work.
4. Build six to eight concise, evidence-based stories from real experience.
5. Adapt the mix to the company and the recruiter-provided loop.

## Evidence and scope

This is an enrichment module, not part of the Striver A2Z syllabus. Company-specific process details change; use company career pages and recruiter instructions as the current source of truth. The added topics reflect the recurring categories in published interview guidance and common mid-level engineering expectations, not a guarantee that every company will test each topic.
