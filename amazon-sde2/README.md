# Amazon SDE-2 Interview Prep

## What to expect
- 4–5 rounds: 2 coding + 1 system design (HLD) + 1–2 behavioral (LP-heavy)
- Coding: 45 min each, 1–2 LeetCode-style problems
- SDE-2 bar: clean code, optimal complexity, edge cases, able to extend the solution
- Amazon weights LP (Leadership Principles) extremely heavily — every round has LP questions
