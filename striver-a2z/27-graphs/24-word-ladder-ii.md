# 24. Word ladder II

← [Word ladder I](23-word-ladder-i.md) · [Part 27 index](README.md) · Next → [Dijkstra's algorithm](25-dijkstra.md)

> [!abstract] Problem at a glance
> **Task:** Return **all** shortest transformation sequences from `beginWord` to `endWord` (each as a list of words).
> **Key insight:** Do it in two phases. **Phase 1:** BFS layer by layer and record each word's depth, removing a layer's words from the dictionary only **after** the whole layer is processed, so two parents on the same layer can both reach a child. **Phase 2:** backtrack from `endWord` to `beginWord`, stepping only to neighbours exactly one level shallower. This explores only shortest-path edges, never storing whole paths in the queue.
> **Difficulty:** Hard · **Pattern:** BFS layers + backtracking over the shortest-path DAG · **Also on:** LC 126
> **Source:** [takeuforward problem](https://takeuforward.org/learning/dsa/word-ladder-ii?category=shortest-path-algorithms&source=strivers-a2z-dsa-sheet) · **Time:** 40 min

## 1. Problem

Same rules as Word Ladder I. Return every shortest sequence `[beginWord, …, endWord]`, in any order. Return `[]` if none exist.

| Input | Output | Why |
|---|---|---|
| `begin = "hit", end = "cog", list = ["hot","dot","dog","lot","log","cog"]` | `[["hit","hot","dot","dog","cog"],["hit","hot","lot","log","cog"]]` | two shortest ladders of length 5 |
| `same, without "cog"` | `[]` | unreachable |

**Constraints:** `1 ≤ L ≤ 5`, `1 ≤ |wordList| ≤ 500`, at most 10⁵ answers.

---

## 2. Approaches at a glance

| Approach | Idea | Time | Space |
|---|---|---|---|
| BFS over whole paths | queue holds sequences; erase a layer's words after the layer | exponential in the worst case | exponential |
| BFS depth map + backtracking | depth per word, then DFS back from end | O(N·L²·26 + paths·len) | O(N·L) |

> [!tip] Interview angle
> The naïve 'BFS storing full paths in the queue' is what Striver codes first. It passes small inputs, but blows up in memory when many paths share prefixes. The depth-map + backtrack version is what LC's tightened tests require. Explain the layer-removal rule clearly: it is the bug everyone hits.

---

## 3. BFS over whole paths

**Intuition.** Queue entries are full paths. Process level by level, extending each path by every unused neighbour; collect paths that end at `endWord`, and stop after the level where the first one appears. Words used in a level are removed from the set only after the level.

```python
def ladders_paths(begin, end, words):
    s = set(words)
    if end not in s:
        return []
    level, res = [[begin]], []
    s.discard(begin)
    while level and not res:
        used, nxt = set(), []
        for path in level:
            w = path[-1]
            for i in range(len(w)):
                for c in 'abcdefghijklmnopqrstuvwxyz':
                    cand = w[:i] + c + w[i + 1:]
                    if cand in s:
                        used.add(cand)
                        p = path + [cand]
                        (res if cand == end else nxt).append(p)
        s -= used
        level = nxt
    return res
```

**Complexity:** time **exponential in the worst case**, space **exponential**.

## 4. BFS depth map + backtracking

**Intuition.** BFS from `beginWord` assigning `depth[w]`. Neighbours are generated by letter substitution, and a word is assigned on first discovery (the depth map is the visited set). Then DFS from `endWord`: from `w`, generate neighbours `p` with `depth[p] == depth[w] − 1`, prepend them, and emit the path when `beginWord` is reached.

**Algorithm**

1. `s` = set(wordList); return `[]` if `endWord ∉ s`.
2. BFS: `depth[begin] = 0`; for each popped `w`, every neighbour `n ∈ s` not yet in `depth` gets `depth[w] + 1`. Stop expanding once `endWord` has a depth.
3. If `endWord` has no depth, return `[]`.
4. DFS from `endWord` with `path = [endWord]`: for each neighbour `p` with `depth[p] = depth[w] − 1`, recurse. At `beginWord`, record the reversed path.

**Dry run** — Depths: hit 0, hot 1, dot/lot 2, dog/log 3, cog 4. Back from cog: dog(3) → dot(2) → hot(1) → hit; log(3) → lot(2) → hot → hit. Two paths.

**C++**
```cpp
unordered_map<string, int> depth_;
unordered_set<string> dict_;
vector<vector<string>> res_;
vector<string> path_;
string begin_;
void back_(string w) {
    if (w == begin_) { res_.push_back(vector<string>(path_.rbegin(), path_.rend())); return; }
    int d = depth_[w];
    for (size_t i = 0; i < w.size(); i++) {
        char orig = w[i];
        for (char c = 'a'; c <= 'z'; c++) {
            if (c == orig) continue;
            w[i] = c;
            auto it = depth_.find(w);
            if (it != depth_.end() && it->second == d - 1) { path_.push_back(w); back_(w); path_.pop_back(); }
        }
        w[i] = orig;
    }
}
vector<vector<string>> findLadders(string begin, string end, vector<string>& words) {
    dict_ = unordered_set<string>(words.begin(), words.end());
    depth_.clear(); res_.clear(); path_.clear(); begin_ = begin;
    if (!dict_.count(end)) return {};
    depth_[begin] = 0;
    queue<string> q; q.push(begin);
    while (!q.empty() && !depth_.count(end)) {
        string w = q.front(); q.pop();
        int d = depth_[w];
        for (size_t i = 0; i < w.size(); i++) {
            char orig = w[i];
            for (char c = 'a'; c <= 'z'; c++) {
                w[i] = c;
                if (dict_.count(w) && !depth_.count(w)) { depth_[w] = d + 1; q.push(w); }
            }
            w[i] = orig;
        }
    }
    if (!depth_.count(end)) return {};
    path_.push_back(end);
    back_(end);
    return res_;
}
```

**Java**
```java
static Map<String, Integer> depth_;
static List<List<String>> res_;
static LinkedList<String> path_;
static String begin_;
static void back_(String word) {
    if (word.equals(begin_)) { res_.add(new ArrayList<>(path_)); return; }
    int d = depth_.get(word);
    char[] w = word.toCharArray();
    for (int i = 0; i < w.length; i++) {
        char orig = w[i];
        for (char c = 'a'; c <= 'z'; c++) {
            if (c == orig) continue;
            w[i] = c;
            String p = new String(w);
            Integer pd = depth_.get(p);
            if (pd != null && pd == d - 1) { path_.addFirst(p); back_(p); path_.removeFirst(); }
        }
        w[i] = orig;
    }
}
static List<List<String>> findLadders(String begin, String end, String[] words) {
    Set<String> dict = new HashSet<>(Arrays.asList(words));
    depth_ = new HashMap<>(); res_ = new ArrayList<>(); path_ = new LinkedList<>(); begin_ = begin;
    if (!dict.contains(end)) return res_;
    depth_.put(begin, 0);
    ArrayDeque<String> q = new ArrayDeque<>();
    q.add(begin);
    while (!q.isEmpty() && !depth_.containsKey(end)) {
        String cur = q.poll();
        int d = depth_.get(cur);
        char[] w = cur.toCharArray();
        for (int i = 0; i < w.length; i++) {
            char orig = w[i];
            for (char c = 'a'; c <= 'z'; c++) {
                w[i] = c;
                String n = new String(w);
                if (dict.contains(n) && !depth_.containsKey(n)) { depth_.put(n, d + 1); q.add(n); }
            }
            w[i] = orig;
        }
    }
    if (!depth_.containsKey(end)) return res_;
    path_.add(end);
    back_(end);
    return res_;
}
```

**Python**
```python
from collections import deque

def find_ladders(begin, end, words):
    s = set(words)
    if end not in s:
        return []
    s.add(begin)
    depth = {begin: 0}
    q = deque([begin])
    def nbrs(w):
        for i in range(len(w)):
            for c in 'abcdefghijklmnopqrstuvwxyz':
                n = w[:i] + c + w[i + 1:]
                if n != w and n in s:
                    yield n
    while q and end not in depth:
        w = q.popleft()
        for n in nbrs(w):
            if n not in depth:
                depth[n] = depth[w] + 1
                q.append(n)
    if end not in depth:
        return []
    res, path = [], [end]
    def back(w):
        if w == begin:
            res.append(path[::-1])
            return
        for p in nbrs(w):
            if depth.get(p, -1) == depth[w] - 1:
                path.append(p)
                back(p)
                path.pop()
    back(end)
    return res
```

**Complexity:** time **O(N·L²·26 + paths·len)**, space **O(N·L)** — the BFS touches each word once; backtracking follows only edges between consecutive depths, so every branch completes into a valid answer.

---

## Edge cases

- `endWord` absent or unreachable: `[]`.
- `beginWord` equals a dictionary word: it still has depth 0.
- Many equal-length ladders: all must be returned.

---

## Common mistakes

1. Removing a word from the set as soon as it is reached **within** a layer, which loses alternative same-layer parents.
2. Backtracking forward from `beginWord` using depth + 1, which wanders into dead ends that never reach `endWord`.
3. Continuing the BFS after the layer containing `endWord`.

---

## Follow-ups

1. Why backtrack from end, not begin?
2. Memory blow-up in the path-queue version?

<details><summary>Answer sketches</summary>

**#1:** Every node one level shallower that is a neighbour lies on a shortest path to `end`; going forward from `begin` you can't tell which branches reach `end`.

**#2:** The number of partial paths can be exponential; the depth map stores one integer per word.
</details>

## Flashcards

**Word Ladder II two phases?** #flashcard
BFS for depths, then backtrack from end via depth − 1 neighbours.

**Layer-removal rule?** #flashcard
Remove a layer's words only after the whole layer is expanded.

**Why backtrack from endWord?** #flashcard
Every depth−1 neighbour is guaranteed to be on a shortest path.
